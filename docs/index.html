Dreamcast Linux

Features Downloads Hardware Heritage Wiki GitHub

A Linux distribution for the Sega Dreamcast: a 7.x kernel, a BusyBox base and about 140 userland packages, booting from a GD-ROM on the original 200 MHz SH4 with 16 MB of RAM. Tested on real hardware.

The kernel is built in a Docker environment, the userland is cross-compiled with T2 SDE.

Features

Framebuffer console
640×480 pvr2fb console on the PowerVR2. Plug in a TV or monitor and a Dreamcast keyboard and you have a terminal.
Networking and NFS
The Broadband Adapter (HIT-0400, RTL8139) and the LAN Adapter (HIT-0300) are both supported: TCP/IP, NFS mounts and remote login.
VMU
The Visual Memory Unit is readable and writable as a block device, with the vmufat filesystem and the VMU LCD.
GD-ROM
Native GD-ROM driver. Boot and mount the disc directly, or run from GDEMU or dcload.
Maple bus
Controllers, keyboards and mice are probed and show up as standard input devices.
Userland
About 140 packages on the GD-ROM, mounted writable through overlayfs, in musl or uClibc builds. mksh is the default shell, and fbdoom is included.
Kernel
A current 7.x SH4 kernel with a built-in initramfs, so there is no separate initrd. A custom init of about 5 KB brings the system up.
Upstream first
Kernel changes are sent to mainline where that makes sense, instead of being kept in a private fork.

Heritage

Linux on the Dreamcast is not new. In 2000 and 2001 the GNU/Linux on SEGA Dreamcast team got a full distribution with a 2.4 kernel running on this console. The Linux-SH developers later carried that work into the mainline kernel, which is why a 7.x kernel boots on this hardware today. This project builds on the work of the people who got there first:

Niibe Yutaka
Started the Linux/SuperH port in 1998, with the GNU toolchain and the sh3/sh4 architecture support that every Dreamcast kernel since has been built on.
Yaegashi Takeshi
Author of the original GNU/Linux on SEGA Dreamcast: the patched 2.4.5 kernel and a Debian-based live CD with working X11, networking and framebuffer, in 2001.
Paul Mundt
Long-time upstream maintainer of the SuperH architecture (arch/sh), and the reason Dreamcast support is in the mainline kernel.
Adrian Glaubitz
The current SuperH maintainer, who stepped in to keep arch/sh from being removed from the kernel and still looks after it.
Adrian McMenamin
Wrote much of the Dreamcast's mainline hardware support: the VMU maple-bus driver, the vmu-flash MTD device and the vmufat filesystem.
Marcus Comstedt
His reverse-engineering and documentation of the boot process, the IP.BIN format and the makeip and scramble tools make it possible to build a self-booting disc.
Adrian O'Grady
Packaged and shared the unofficial DcLinux DiscJuggler image (DcLinux-010605, 2001).

Thanks also to the Linux-SH kernel developers, the homebrew and dcemulation scene, and the GCC, binutils, glibc and T2 SDE maintainers.
